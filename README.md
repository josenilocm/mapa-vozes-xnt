# Mapa das vozes XNT

Mapa de bolso responsivo para interpretar as vozes 1NT, 2NT, 3NT e 4NT no leilão de bridge.

O conteúdo segue as apostilas do Curso de Principiantes 2026 usadas no projeto Aprender Bridge. A apostila específica de cada contexto prevalece; divergências entre fluxogramas não foram harmonizadas silenciosamente.

Site estático, sem dependências externas.
